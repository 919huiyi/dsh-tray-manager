# DeepSeek Harness 便捷启动包

## 📁 文件说明

| 文件 | 说明 |
| --- | --- |
| `启动 DeepSeek Harness.vbs` | **一键启动，双击这个**（无终端窗口） |
| `DeepSeek Harness Tray.ps1` | 托盘后台程序（一般无需手动运行） |
| `停止 DeepSeek Harness.bat` | 手动停止服务的备用工具 |
| `DeepSeek Harness.ico` | 托盘图标 |
| `dsh-tray.log` | 运行日志（自动生成，出问题时查看） |
| `DeepSeek  Harness.bat` | 原来的启动脚本（已被替代，可删可留） |

## 🚀 日常用法

1. **启动**：双击「启动 DeepSeek Harness.vbs」
   - 没有任何终端窗口，服务完全在后台运行
   - 就绪后自动打开默认浏览器进入网页端
   - 右下角通知区域出现托盘图标，启动成功有气泡通知
2. **关闭浏览器窗口** = 只是关掉网页，服务仍在后台运行
3. **再次打开网页**，任选一种：
   - 双击托盘图标
   - 托盘右键 → 打开网页
   - 再次双击「启动 DeepSeek Harness.vbs」（服务没在运行时会自动重启）
4. **完全退出**（会同时停止后台服务）：托盘右键 → 退出
5. **只停止服务**（托盘保留）：托盘右键 → 停止服务，或双击「停止 DeepSeek Harness.bat」

## 🖱️ 托盘右键菜单

| 菜单项 | 说明 |
| --- | --- |
| 打开网页 | 打开网页端（服务没在运行会自动启动，就绪后自动打开） |
| 启动服务 | 手动启动服务；启动过程中显示"启动中…"，完成时有气泡通知 |
| 停止服务 | 停止服务（托盘保留，之后可随时重新启动） |
| 重启服务 | 停止后重新启动，操作即时响应、不卡顿 |
| 使用说明 | 打开本文档 |
| 退出 | 停止服务并完全退出（唯一真正的退出方式） |

> 菜单中"服务状态"一行会随服务启停自动变化；启动/重启过程**不会卡住界面**——服务在后台启动，完成时弹气泡通知。

## ⚖️ 资源占用（实测数据）

| 状态 | 私有内存 | CPU |
| --- | --- | --- |
| 托盘空闲（服务未运行） | 约 110 MB | 几乎为 0 |
| Harness 服务运行中 | 约 530 MB | 平时很低，使用时上升 |
| 全部退出后 | 0 | 0 |

> 托盘是 PowerShell 进程，常驻约 110 MB；服务是 Node.js 进程，约 530 MB。**不用服务时点"停止服务"可释放约 530 MB**。托盘空闲占用是否可接受、要不要改成"随服务退出、空闲零占用"，以你的设置为准。

## ❓ 常见问题

- **托盘图标不见了？** 服务可能仍在运行，再次双击 VBS 即可。
- **想彻底清理？** 托盘右键 → 退出；如果托盘也没了，运行「停止 DeepSeek Harness.bat」。
- **服务被别的方式启动了（比如先跑了原来的 bat）？** 双击启动器会直接接管正在运行的服务，托盘「退出」时同样会把它一起停掉。
- **出问题了？** 打开 `dsh-tray.log` 查看记录——启动/停止/重启/托盘启停都有日志。

## 🛠️ 高级参数（一般用不到）

| 参数 | 说明 |
| --- | --- |
| `-Port <端口>` | 指定服务端口（默认 3080） |
| `-NoBrowser` | 只启动服务、不打开浏览器 |
| `-Stop` | 停止服务（供「停止 DeepSeek Harness.bat」调用） |

## 💡 小技巧

- 想放桌面：右键「启动 DeepSeek Harness.vbs」→ 发送到 → 桌面快捷方式
- 想开机自启：把该 VBS 的快捷方式放入 `Win+R → shell:startup` 打开的文件夹
